# 抽卡部门试生产：批量视频

此版本提供真实 CompShare MiniMax-H3 批量队列。自动化验证与真实收费验收分开记录：只有实际生成、人工质量审核与导出都通过，才可宣布真实生产 PASS。没有自动采用、自动付费重试或自动切换供应商。

## 开始生产

1. 安装本次 `batch` 标识的 Windows 包。已有 Alpha 数据保存在原用户目录；更换电脑请使用项目备份/恢复，恢复的收费授权不会迁移。新电脑需在设置重新配置并加密保存公司服务凭据，切到“真实生产”模式。
2. 打开项目 → **分镜视频 → 批量生产**。选择场次，点击 **选择当前场次最新 7 镜头**，核对每条 UUID。该按钮按创建时间选最近七条，准备页仍须人工核对；可逐条勾选、排除历史镜头。
3. 可选：在人物资产中导入合规素材，人工批准后选择为人物镜头首帧。只允许上传已批准图片。H3 当前接入为首尾帧协议，非多人物参考协议；同一人像首帧不保证跨镜头一致性。没有可用首帧时可使用文生视频，质量与一致性须逐镜审核。
4. **准备批次（不收费）**保存所选镜头、正式设定版本、固定描述、首帧、模型与请求数量。不会发送生成请求。只覆盖所选 UUID，不会覆盖或自动选入其他镜头。
5. **审核整批范围与预算**，展开提示词核对范围。只在这里集中确认一次。H3 480P 使用整数 4–30 秒，非整数分镜向上取整，分镜设定保持不变。原生账户预算以 PTS（积分）绑定，每镜预留 5 × 秒数积分，不折算人民币。人民币费用未知，本地人民币记账预留为可选字段；有人民币硬上限要求时先设置供应商账户限额。
6. **授权并启动整批真实生成**。同批每镜最多一次 POST，固定供应商/模型，串行调度。授权 24 小时有效。每镜独立保存 Task、GenerationRecord 和候选版本，实际费用未知继续占用预留。点击 **暂停后续提交**只停止尚未提交项，已提交任务继续查询回收，不承诺取消远端计费。

## 选片、返工、成片

- 点击某镜 **审看/选片**，在下方播放器检查动作、景别、人物、服装、道具、连续性及面容。点击“批准”后仍未采用；满意后明确 **设为当前镜头视频**。已采用状态与 UUID 持久化保存。
- 失败或质量未通过可点击 **单镜头返工预览**。仅创建一条未授权的新批次，保留原结果，其余成功镜头不受影响；不会花第二次钱，直到人工确认新预算。未知提交不能返工补发，须先由管理员核实供应商原任务。
- 每镜均已人工采用后，点击原 7 镜批次的 **按已采用镜头合成并导出 MP4**。按正式镜头顺序合成，无声 MP4，显示实际素材总时长；不会擅自裁回分镜建议时长。尺寸统一到首镜，帧率 24，保留画面比例并加边，不生成额外内容。
- 导出的成片同时入库，可 **预览已导出成片**；保存对话框取消只取消外部复制，已入库成片仍保留。重启后仍能预览、导出。

## 暂停、恢复与故障

- 重启后批次保留并暂停后续付费提交。点击 **恢复原批次**继续原授权内尚未提交项；已知远端任务只查询原 ID，不重新提交。过期授权或正式设定变化须重新准备范围和预算。
- 批次表展示镜头、关联名称、UUID、模式、实际请求时长、状态、Task ID、Record ID。反馈时提供批次 ID、镜号、Task/Record ID、错误类别、发生时间、应用版本。高级诊断可检查素材和日志；不要发送密钥或完整签名下载地址。
- HTTP 拒绝、超时和断网不会触发第二次生成。未知状态保留费用未知、预算占用和原始身份，交管理员核实。只读查询失败保留原任务以便恢复。
- 对已接受、仅本地输出校验失败的 H3 任务，可明确点击 **查询回收原结果（不重生成）**，只查询同一个远端 ID 和下载结果，不建立新收费任务。原校验失败证据保存在回收候选来源中。未知提交或普通生成失败不能走此入口。
- 本次真实 4、5、6 秒请求分别观测到约 4.458、5.167、6.583 秒的视频，H3 时长校验保留一秒以内偏差，并记录实际时长；不能把请求秒数当作素材实际秒数。容器、MIME、尺寸、受控下载和 hash 校验继续执行。
- 队列保守并发为 1；任何未完成或未知的同供应商任务会阻止追加自动提交。账户余额仍在每次实际提交前只读检测；不通过时本镜失败且不发送生成。
