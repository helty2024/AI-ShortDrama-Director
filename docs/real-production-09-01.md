## 已实现

- 全局 AI 服务：文本、Packy 原生图像、CompShare H3 原生视频、本地 ComfyUI 分组。支持配置、加密录入/导入/换钥、只读检测、默认、停用和保留历史数据的归档删除。普通页面没有原始技术表格。
- 文本复用 CompatibleTextProvider 严格 JSON Schema；不配置环境变量即可修改后续任务使用的模型。只读模型列表不能解锁结构化生成，用户需另行确认可能收费的小型协议请求。故事整理/解析实际调用模型；角色、场景、道具和分镜沿既有分析队列调用同一默认模型。生成结果经过已有 Schema，禁止失败后回退到本地规则。
- 真实文本请求关闭自动重试，输出限制 4000 tokens；任务保留服务身份、配置修订与模型。启动和重试均需用户确认真实内容发送与可能费用。文本尚未经过任何真实供应商成功验收。
- Packy 使用固定原生地址、模型与映射，不需要普通用户手写 Profile JSON。正式包装器逐能力验证单次试验或真实结果入库证据；当前价格未独立报价，使用未知费用授权，历史 USD 0.4000 不作当前保证报价。
- H3 使用官方原生 API，Idempotency-Key 仍来自 generation attempt 的 UUID。默认仍关闭。可在明确授权的 4 秒单次测试中验证真实任务协议与 MP4 下载；尚无成功任务时不依赖预先填写 CDN。成功前不开放正式批量生产。
- 下载校验从固定鉴权 API 取得指定任务结果，严格验证 task/model/status、HTTPS、精确域名、公网 DNS 固定、无重定向下载、大小、MIME、MP4 容器与时长；只保存域名/哈希等证据，不保存签名 URL。首次授权任务的下载域名只来自固定鉴权 API 的同一任务结果，并与本地记录/审批/提交意图及 task_id 严格绑定；仅对该任务建立精确域名许可，下载禁止重定向。真实媒体验证后保存域名与哈希。后续生产只允许已经验证的精确域名，没有 suffix 通配放宽。
- 试验授权限定能力、有效期和单次意图；视频首试限 4 秒 480P。官方当前参考单价 5 积分/秒，预计 20 积分，不能折算人民币。可用余额在真实视频预检与提交前重新只读查询。
- 试验提交之前写入独占的持久化消费标记及任务意图，并发或崩溃不能重复消费同一授权。未知提交不重试、不释放为已知免费，不允许新增付费试验绕过待核实任务。已知 task_id 沿原机制恢复查询。
- 批准与采用、AssetVersion/GenerationRecord/lineage、审批与预算预留仍沿原有规则。AUTO 排除尚未有真实结果证据的 Packy 试验能力；指定试验入口固定选择对应原生工具。
- Seedance/Compatible 历史配置仅保留高级入口；未经真实核验的协议不列为普通真实服务模板。

## 凭据和工作流操作

设置 → AI 服务 → 对应分组 → 添加服务。密钥在软件内密码框输入或从本机 txt/key 文件导入，保存后清空输入框。密钥不会进入普通 JSON、SQLite、诊断、Git 或截图。文本模型需检测连接、验证结构化能力、设为默认。

图像和视频配置只读检测后，打开真实生成测试，选择项目目标及能力，准备单次试验。该动作不发生成请求；生成页仍需再次确认单次费用授权及内容/参考素材发送。未知费用不是零，本地授权预算不能保证供应商结算封顶；需核对账户价格与额度。

既有任务下载检测不上传素材、不消费生成积分。首次收费试验须独立授权；收到任务结果后先执行任务绑定的下载安全检查和真实媒体验证，成功入库才形成该能力的生产证据。未经审批或不能证明属于本次已接受任务的 URL 不允许进入下载路径。

服务配置修改期间保护待执行任务与有效预览；需要先完成或取消制作，过期预览等待失效。原配置修订及加密凭据引用保留，不静默删除用户数据。
