# 诊断与错误中心

验收与维护 → Export Diagnostics 使用原生保存对话框导出 JSON。采用白名单组织数据：应用/构建/平台/schema、公开 Provider model/endpoint、标准化任务错误、工作流验收结果、FFmpeg/FFprobe 版本和最近任务状态日志。

不导出剧本文本、Prompt、素材名/路径、原始图像/视频、API Key、credentialRef、加密凭据 blob 或原始异常堆栈。不直接序列化完整任务或整个数据库。网络异常按统一类别转换为用户可读原因，避免远端响应泄露请求内容。诊断包不是原始操作日志归档。

任务中心与 Error Center 集中展示失败文本/图像/视频/QC、缺失凭据、Comfy 诊断问题、源数据变化及已检测 FFmpeg 问题，提供重试、取消、设置和镜头检查入口。失败任务的远端 ID 保留以恢复下载，用户不应另开同一付费任务来绕过不明提交。迁移发生在 renderer 启动之前，启动失败使用原生提示，不声称错误中心已成功加载。
