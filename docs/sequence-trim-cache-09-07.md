# 09-07 移出镜头区间恢复

日期：2026-10-27。分支：`codex/09-01-test-ready-alpha`。

- 正式项目「项目成片」面板使用本组件内的 `useRef` 缓存移出镜头的区间：每个镜头只保留最近一次版本与入点/出点，最多 100 条；复用时同时匹配镜头 ID 和采用版本 ID。行内移出、勾选后重建移出均适用，移出最后一镜也保留本次会话记录。
- 建线优先保留当前草稿中的同镜同版本区间（含原有暂时无效编辑），返回镜头再尝试已移出记录。缓存需通过既有剪辑 schema 校验且出点不超过当前源时长；否则使用 `0–源时长`。新版本不会继承旧版本区间，观察到版本变化或镜头移除即删除旧记录，A→B→A 不复活旧记录。
- 重新加入后消费该条缓存，下一次移出记录最新编辑。载入历史时清空缓存并直接采用历史区间，不把被替换的时间线重新放回缓存；切换项目强制重建面板，离开面板时清空缓存。没有数据库、schema、迁移、IPC、preload、权限或依赖变更。
- **冷启动和导航边界**：仅当前时间线中的镜头及区间继续通过现有 `sequenceDraft` 持久化。尚未重新加入的镜头区间不写库，离开页面或重启后重新加入会使用完整时长。空草稿仍恢复为空，不因缓存自动加入镜头；需勾选并建立。界面明确提示此边界。
- 仍为单份草稿，无撤销栈 UI、跨会话缓存、批次时间线移出、云同步。正式顺序验证、无声、100 镜头 / 600 秒、24 fps、首镜分辨率及 FFmpeg 管线不变；不增加任意重排、转场、字幕或音频。未执行 CompShare、Packy、SenseNova 付费生成或付费 E2E。

单元测试覆盖同镜同版本恢复、重复移出采用最新区间、当前草稿优先、负数/倒序/非有限数/越界及源时长缩短回退、版本更换/切回和删除失效、100 条上限及末镜移出。

沿用 `npm run test:smoke -- --grep "formal project offline"`：三镜建线，中镜裁为 `0.125–0.625s`，移出后重新勾选并重建，验证中镜区间恢复且首末镜区间不变；无效移出区间回退完整时长。之后保留中镜移出、勾选同步、导航与冷启动两镜草稿恢复、红→蓝 24 帧导出、两镜/三镜导出命名与历史标签、空草稿冷启动及重新建线检查。额外检查冷启动后返回中镜不恢复旧缓存，以及载入历史清空预先缓存的中镜区间。最终生成记录、AI 任务、生成批次均为零。
