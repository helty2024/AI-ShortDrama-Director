# 09-01 · 三模型受控真实测试

本轮在 `0.9.0-alpha.2` 安装版中使用用户本机提供的配置。只读检测和真实生成分开；用户明确授权文本、图像、视频各一次，不设货币金额上限。图像一次一张，视频一次 4 秒、480P；没有自动重试，也没有将较大的累计用量上限当作批量授权。

## 配置与实现

- 文本：商汤 `sensenova-6.8-flash-lite`，固定到用户指定的 SenseNova 端点。模板使用 `json-prompt`：Schema 约束放在系统提示中，不发送服务文档未说明的格式参数，仍严格校验结构和完成状态。首个用户确认的真实故事任务同时验证协议，避免为一次授权发送额外的验证请求。原有严格模式和 JSON 模式保持原选择，不自动切换。
- 图像：Packy `gpt-image-2.5-flare`，沿用原生图像接口，保留 Sunburst 旧配置兼容。当前 Flare 仅提供单张文生图；不宣称参考图编辑已经验证。该接口返回自动尺寸，实际尺寸由图片解码确认、保存并展示，计划尺寸不是供应商承诺。
- 视频：CompShare `MiniMax-H3`，本轮未修改 H3 原生 Adapter 或通用 Tool Protocol。仍由现有真实生产门禁绑定服务版本、能力、预算、请求指纹和单次任务；未验证能力保持关闭。未知提交不重新 POST，远端身份持久化后只查询原任务。

三个服务的凭据仅以主进程系统加密文件保存，配置只包含凭据引用。未将原始密钥、完整认证头、供应商原始响应或签名下载 URL 写入本报告或 Git。用户提供的本地原始配置文档不属于仓库，未删除用户文件。

## 费用与安全边界

货币费用仍为 unknown，不记为零，也不将积分折算人民币。用户明确不设金额上限时，本次验收在既有单项预算字段中使用可表达的最大安全整数微单位作为技术上限；它不是报价、实际费用或供应商承诺的结算封顶。预算仍按原规则保留，待实际账单人工核对。两次媒体请求分别绑定独立授权与唯一任务，没有修改预算语义或 schema。

H3 任务的幂等键仍由 attempt task UUID 生成，同一 attempt 稳定，新 attempt 不同。只有真实输出经过安全下载、媒体校验和入库后，才可形成该能力的验证证据。只读余额、模型可见和任务受理均不能替代 MP4 验收。
