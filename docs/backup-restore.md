# 项目备份与恢复

在验收页选择 Backup Project，使用原生目录选择器指定父目录。生成独立 director-backup-UUID 目录，包含 project.sqlite、media/ 和最后写入的 manifest.json。先等待或取消项目运行中的生成/QC 任务。备份只含一个项目及其实体、草稿、版本、历史任务、连续性/QC、公开配置与工作流。不会复制凭据文件、密钥明文、加密 blob、全局 settings、临时付费提交预览或其他项目。自定义 workflow 的凭据类字段会清空；不要将密钥硬编码在自由文本里。

Restore Project 选择该备份目录，校验 schema、SHA-256、文件真实目录、数据 Zod schema、行身份、项目范围和外键。成功时创建名称带“（恢复）”的新项目；项目、实体、版本、任务及关系 UUID 和媒体存储键重映射，不覆盖现有项目。文件校验失败不会写入数据库；后续提交失败回滚事务并清理新建媒体目录。

恢复项目需要重新绑定 Key。历史远程 ID 被清空，未完成任务不会自动提交；请通过新预览生成需要重做的任务。不要依赖恢复副本接管原项目的远程付费任务。备份格式 1 使用 schema 6；当前恢复器接受此格式。v1–v5 工作台数据库先由正常启动迁移至 v6 后再备份，不直接把任意旧 workspace.sqlite 当作备份。

复制中断会留下未完成目录，其缺失 manifest 或 hash 不匹配会被拒绝恢复。文件系统与 SQLite 不提供跨系统事务，manifest 是备份完成边界；请将完整目录存放到可靠位置。备份不加密，应按项目素材的敏感程度管理访问权限。验证报告与临时恢复状态不作为生产实体恢复。
