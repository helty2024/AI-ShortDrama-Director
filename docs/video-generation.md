# 视频生成与审核

## 无 Key 可操作流程

1. 安装 FFmpeg/FFprobe，打开示例项目，在设置点击“测试视频 Provider”，应显示 Mock Video Ready。
2. 分镜打开“批量关键帧生产”，选多个 Shot，编译并生成。每个结果独立进入 AssetVersion draft。
3. 某 Shot 展开“视觉生产”，审核关键帧并批准绑定。视频必须从该固定图片版本出发。
4. 展开“视频生产”及“导演动作信息”，编辑开始/过程/结束、主体/摄影机/环境运动、表演、速度与连续性，保存。
5. 选择 Profile、该能力支持的时长、分辨率及可选尾帧。编译视频 Prompt 后可编辑动作段，再生成。
6. 队列完成后，展开生成信息播放 MP4。Approve 只提升资产主版本，Confirm for Shot 才固定正式镜头视频。
7. Regenerate 载入原视频动作 Prompt 和时长供修改，再生成新版本。选择两版进行 A/B，Reject / Archive 不改变旧文件。确认新版本前旧正式视频保持不变。

更换首帧需在视觉生产重新明确批准并绑定图片，再编译视频。云 Profile 提交前须勾选可能产生费用确认；未知价格不是免费。

## 连续性与界限

VideoPromptCompiler 使用当前 keyframe、角色面容/发型/服装、地点光照/天气、道具状态、场次时间及上一 Shot 的确认视频/关键帧 ID 构造规则上下文；ID 放入 providerHints 追踪。当前首帧适配器实际发送首帧/可选尾帧和文本，不把上一视频上传做视觉自动 QC。

Mock 输出由首帧循环形成真实 H264 MP4（12 fps），验证完整生命周期，不模拟真实 AI 动作质量。保存版本时读取实际元数据。当前不含成片剪辑、音频混合或批量整集云视频提交。

## 异常处理

超时、下载失败或磁盘失败后点击任务重试，会查询相同远端 ID。远端已经 failed/cancelled 的 ID 不重新提交；需要新生成时明确使用“生成视频”。提交回执仅有 submitting 状态时，本地无法判断远端是否收单，系统阻止重交；先到 Provider 控制台核对。应用重启自动恢复有远端 ID 的运行中任务；未取得 ID 的中断任务保留失败供检查。

## Phase 5 更新

可在生产看板进行规则连续性、批量视频、QC 和单次重生规划。旧版单 Shot 视频生产仍可使用，所有生成版本现在记录连续性指纹。完整闭环见 [生产看板](production-board.md)，QC 是辅助审核，不直接替用户 Confirm。
