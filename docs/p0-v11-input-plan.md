## 镜头 5：停笔 → 转向窗外

生成 5 秒，剪辑目标 4.5 秒。中近景，保持正式分镜的侧方偏正面机位与缓慢推近。四个阶段为 0–1 秒停笔、1–3 秒轻转头并移目光、3–4.5 秒凝视窗外、4.5–5 秒留剪辑余量。具体剪辑入出点仍由审片确定。

- 首帧 5A：同一成年林夏、米色针织衫、随意束发；坐在同一靠窗木桌，目光落在打开的未完成素描本，手中握削好的铅笔，笔尖接近纸面。素描本朝人物方向正常摆放，图画不可倒置。左侧窗光与窗外可辨的金黄色秋叶建立空间。
- 尾帧 5B：同一脸、服装、发型、座位及道具布局；停笔后铅笔仍自然握持并略悬于原纸面，头轻转、眼望同一窗外方向，尚未明显微笑。只完成正式分镜允许的动作，不新增放笔动作；推近量小，不跨轴。
- 人物身份：由人工采用的林夏主参考确定，5A/5B 必须人工核对为同一人。主参考用于制作和审核关键帧，**不作为第三张 reference_image 与首尾帧混传**。
- 衔接：镜 3 的持笔状态经过镜 4 窗外空镜后，镜 5 回到同一桌前；不得把镜 4 当成手部动作连续发生的证据。镜 5 末的头向、目光方向、光线，交给镜 6 首帧承接。

建议视频描述：

> 单一连续镜头。人物面容、米色针织衫、束发、桌面和素描本布局严格保持首尾帧。林夏先停下铅笔，随后轻侧头，目光从未完成的画移向同一窗外金叶；铅笔始终自然握持，手保持在纸面附近。左侧窗光不变，窗外秋叶可辨。缓慢小幅推近，保持既定轴线；最后停留凝视，尚不展开下一镜的微笑。不要新增人物、翻页、倒置画作、放笔、杯内饮品或蒸汽。总生成 5 秒，最后半秒为自然停留。

## 镜头 6：凝视 → 温柔微笑

生成 5 秒，剪辑目标 4.5 秒。正式分镜的平视微侧面部特写，左侧窗光；固定或几乎不可察觉地推近。

- 首帧 6A：由 5B 的同一角色状态衍生特写，保持头向、画面外窗户的目光方向及左侧光源；嘴角放松，未开始明显微笑。更近的机位不改变身份或反转空间关系，不要求直接复用同尺寸图而丢失正式景别。
- 尾帧 6B：仅嘴角缓慢轻扬、眼神柔和，温柔满足的自然闭口微笑；头向和视线保持，不突然看向镜头。保持米色针织衫可见部分与束发轮廓；不把镜 5 的桌面道具硬塞入面部特写。
- 节奏：0–1.5 秒承接凝视，1.5–3.5 秒表情细变，3.5–5 秒自然保持。不是瞬间换脸、夸张笑容或大幅转头。
- 衔接：6A 与 5B 是同一时刻姿态的不同景别；6B 的情绪留给镜 7，但镜 7 的画作方向、窗外信息和人物一致性仍须另行修复与审核。

建议视频描述：

> 单一面部近景特写，沿用首尾帧中同一林夏的面容、束发和米色针织衫。承接上一镜望向窗外的头向与目光，保持左侧窗光。先宁静凝视，随后嘴角缓慢扬起轻微闭口微笑，眼神转柔；不突然看镜头、不大幅转头、不换脸。机位固定或极轻微推近，5 秒内只完成这次细微表情变化，末尾自然保持。无新增人物、文字或道具。

## 实际 H3 映射与提交条件

每镜快照使用 `purpose=narrative-production`、`mode=image-to-video`、480×864、24fps、5 秒、9:16、无 seed。首帧必须等于该正式镜头的 `approvedKeyframeVersionId`；尾帧必须属于本镜头或同场次相邻下一镜头，并已批准、采用为素材主版本。手工输入素材先经过正式审核与镜头关联，禁止只凭文件名判断归属。

请求体采用 `model=MiniMax-H3`、`resolution=480P`、`duration=5`、`ratio=9:16`、`mute_audio=true`、`use_context_ir=false`。`content` 仅一个 text、一个 first_frame 和一个 last_frame；帧由本地已登记且 hash 通过的版本读出后构造 Data URL。无外部任意路径或额外 reference_image。

准备、费用确认及执行前重新检查资产 UUID、修订、项目归属、批准/采用指针、实体修订和证据摘要；摘要变化需重新准备与授权。请求指纹和批准项、预览、任务、GenerationRecord 绑定，未知状态禁止重发。

## P1 声音待确认

当前 H3 适配器固定 `mute_audio=true`，请求只允许 `audio=none`。本地合成 `-an`，界面明确标为无声。该开关会移除全部输出音轨，不能用来“保留对白但去掉参考音频”。当前无声技术链不证明对白或音画同步可用。

| 部门需求 | 状态/待确认内容 |
|---|---|
| 对白/旁白 | 待确认是否需要、文本、说话人、语言及断句 |
| 音色 | 待确认声线、授权素材、复用范围；不推定允许克隆 |
| 环境音 | 待确认咖啡馆、窗外声的具体内容及音量 |
| 动作音效 | 待确认铅笔、纸张等是否需要；不自动添加 |
| 音乐 | 待确认配乐需求、授权来源、进入/结束点及混音 |
| 音画同步 | 待确认口型、对白时间轴、字幕及技术指标 |
